# 选择方法：问题、段落任务与可用素材

这是选择入口，不代替完整方法卡。先辨认要改哪里和为什么，再读取相应文件中所选的完整条目。编号沿用 Wiki，深化卡用 E 编号；均不展示为用户必须理解的术语。

## 按问题找方法

| 观察到的具体问题／机会 | 先读什么 | 怎么挑 |
|---|---|---|
| 报告腔、翻译腔、词太正式、嘴上说不出 | [自然口语](methods/01-natural.md) 1–4；E03 | 术语需要解释，书面词需要换说法，关系缺失需要补完整，三者别混用 |
| 一句讲几件事、缺谁／什么／条件 | [自然口语](methods/01-natural.md) 4；[讲清楚](methods/02-clarity.md) 6–8、11；E02 | 先补对象和逻辑；自然中句可保留，不按字数硬切 |
| 新闻／技术懂字面但不知与人何关 | [讲清楚](methods/02-clarity.md) 8–10；[共鸣](methods/04-emotion.md) 23–25；E01 | 先说明是什么，再落到材料支持的具体处境、选择或代价 |
| 好、难、专业、靠谱等评价空泛 | [证据](methods/03-evidence.md) 12–14、21；[举例](methods/06-examples.md) 40–42 | 有事实拿事实支撑；没有就标缺口，不靠更多形容词 |
| 已有真实资历、亲手做过的事或有出处的专家意见，却没交代与判断的关系 | [证据](methods/03-evidence.md) 15、19 | 交代来源为什么相关，保留身份与引文归属；不冒领资历、不虚构背书 |
| 很大、很累等抽象感受难感知 | [共鸣](methods/04-emotion.md) 22；[举例](methods/06-examples.md) 38、41；E07 | 直接场景与类比不同；先看真实细节，再看类比是否更易懂 |
| 情绪已经能感到，却又反复解释 | [共鸣](methods/04-emotion.md) 27–29；E09 | 有真实动作／物件才承载情绪；没有不强造，留白不藏事实关系 |
| 冗长重复、同速、没有新信息 | [节奏](methods/05-rhythm.md) 30–37；E05、E08 | 删无信息重复，保留强调、递进的复现；不靠堆名词增密度 |
| 有事实但判断软、重点偏移 | [自然口语](methods/01-natural.md) 5；[节奏](methods/05-rhythm.md) 35–36；[语气](methods/07-voice.md) 51；E04 | 换准确动词、调整落点；不能扩大可能性或范围 |
| 观点容易引起误解或反对 | [证据](methods/03-evidence.md) 13、17–20；[节奏](methods/05-rhythm.md) 34、37 | 反驳真实主张；不造稻草人，不用问句暗示无依据事实 |
| 一直转述、场景不鲜活 | [证据](methods/03-evidence.md) 16；[语气](methods/07-voice.md) 49–50；E06 | 有原话才引用；有真实念头才写内心；不用假对白造现场 |
| 说教、炫耀、推销、强行煽情 | [共鸣](methods/04-emotion.md) 23–26、29；[语气](methods/07-voice.md) 43–48；E01 | 调整与读者的关系；不为温和而磨平原立场 |
| 顺畅但不像本人 | [语气](methods/07-voice.md) 44、50、52；E10–11 | 没样本先正常优化；有样本再校准，不虚构亲历、口头禅或人格 |
| 用户说修改后仍不顺、指出具体问题或推翻上一版选用的技巧 | E12；再按新问题回到上表 | 结合原稿、上一版与这次反馈修当前问题，保留已认可部分并交合并稿；不把局部反馈变成永久偏好 |
| 参数／卖点像说明书 | [讲清楚](methods/02-clarity.md) 8、10；[举例](methods/06-examples.md) 38–42；[语气](methods/07-voice.md) 48 | 对应真实使用场景，不升级功效和可用范围 |
| 用户只问怎么念、声音平、像背稿 | [念稿配合](performance.md) | 文本改好不等于表演已好，需要音频时明确边界 |

“E…”见 [来源深化卡](practice-notes.md)。主方法足够时不额外加载。

用户点名的写法不在问题表中时，在 [完整对应表](coverage.md) 按方法名称定位，再读完整卡片；路由是常见问题入口，不是可用方法的白名单。

## 用段落任务校准

| 段落要完成什么 | 组合方向 |
|---|---|
| 讲清陌生的事 | 对象与背景 → 白话解释 → 必要的例子／类比 |
| 证明一个判断 | 明确判断 → 真实行为、数字、对比 → 成立条件 |
| 呈现人的经历 | 已有处境、行动、原话 → 真实反应 → 必要交代 |
| 让读者产生感受 | 目标读者的真实处境 → 具体细节／行为 → 分寸与留白 |
| 比较选择或照着做 | 比较标准／步骤 → 原因与条件 → 材料支持的结果 |
| 让理解往前走或收住 | 接住已知 → 新信息／转折 → 自然落点 |

一段可以承担两个任务，不强制固定结构。方法以当前材料为准；角度已定不重新选题。

## 相近方法别合并

- **21 评价换事实**：用行为支撑“细心、靠谱”等判断。
- **22 抽象换画面**：把程度／感受变成可感知的动作、场景或尺度。
- **28 物件与留白**：情绪已成立时少解释，让真实物件或动作承载它。
- **38 比喻**：借另一样熟悉的事物；对应关系必须准确。
- **40 举例**：具体事说明道理；真实例子需材料，假设需当前任务许可并标明。
- **30 删废话**是减无用部分；**31 信息密度**检查剩下的话有无用；**32 排比／E08 复现**可以有意重复。
- **9 段落先给答案**与**35／E04 句末落重点**是不同层级，不互相取消。
- **43 对观众说**不等于加“你”；**44 第一人称**不等于冒领亲历；**52 个人声音**不等于固定口头禅。
