# expression-polish 首次使用产物

## 完整优化稿

书架分区后，店员可以按预约、待归还两类找书。试行一周，记录到一次取错书。但之前没有统计取错书的次数，所以现在还不能判断出错率有没有降低。

## 这次用了什么

- 用平时说话的口气 → “在书架分区实施完成以后”改成“书架分区后” → 去掉公文式的层层套话，保留先后关系。
- 删掉没有新增信息的词 → “在针对相关书籍进行查找时”收成“找书” → 对象仍然是书，动作更直接。
- 保留判断边界 → 保留“一周”“记录到一次”和“还不能判断出错率有没有降低” → 没有把试行记录改成效果证明，也没有加效率或成本收益。

按共同材料，把“归还”具体写成“待归还”，把“数量方面的统计”明确为取错书次数；没有扩写小林的行动或补进段落原本未讲的标日期细节。已做文本层面的对照回读，未做真人试读或受众测试。
