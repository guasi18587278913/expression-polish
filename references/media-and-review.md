# 媒介适配、相反建议与复检

本页是多文体改稿的执行适配。Wiki 素材以短视频为主；以下分流是技能设计，不是已验证的传播定律。

## 媒介

### 口播稿
- 以听一遍能理解、能自然说出来为目标。补清对象、前因后果和条件，再拆过载句。
- 可含自然中句、停顿和有用的语气；不强制每句一行，不把所有连接词换成“然后”。
- 无视频信息时文字必须自足。只有明确给出画面／动作，才考虑信息交给画面；不能因为原书提倡表演就删必要台词。
- 气口用自然标点或段落体现；未要求时，不每句插“停顿／重读”等舞台指令。
- 本人试读才能检验实际顺口与语气；无录音时只说明文本检查。

### 公众号文章／长文
- 保持自然段、论述关系和阅读节奏。准确自然的书面表达可保留，不拆成提词器或直播话术。
- 保留必要术语，首次说明后可沿用；不为口语化损失精确性、论证或克制的态度。
- 比喻、对比、留白、对白须在文字中独立成立；无视听辅助不能省关键语境。
- 不自动加“大家好／你们懂吗”、互动提问、涨粉结尾或个人经历；有意修辞和自然中长句可保留。
- 选取短视频方法的表达动作，不复制固定秒数、互动方式和效果承诺。

### 短文案／图文配字
- 保留主张、真实功能、受众和行动目的；优先准确直接，必要限制可以比口号长。
- 不凭空增加稀缺性、价格、时限、效果或行动入口；未要求广告化时不加押韵、感叹号、“赶紧买”。
- 未看到图片时不假定图片补全了文字；明确知道配图内容才利用图文分工。

### 指定风格
当前指定优先。可保留正式、冷静、幽默、方言等要求；自然不等于全部亲昵活泼。样本提供词汇、句法、节奏和态度参考，不借样本的事实、身份、经历或口头禅。

## 相反建议

| 建议 | 选择条件 |
|---|---|
| 留语气助词／删“嗯啊” | 承载态度、自然接话的可留；打断意思、反复卡住的删。纯文字不能判定所有声音填充 |
| 删重复／复现关键词和句式 | 去掉后信息、情绪推进和节奏不损失的可删；每次新增动作、后果或意义的可留 |
| 短句／保持完整 | 完整优先。不能从因果、条件、对比或转折中间硬截；完整但负担重的再拆 |
| 加细节／删铺垫 | 保留后文理解、判断或感受需要的细节；无关天气、路况不铺陈 |
| 先结论／先情境 | 解释建议常先答案；让人感受处境时可先已有场景，沿用已定结构 |
| 强烈／克制 | 强度来自目的与材料；不能因卡片说“更狠”加重事实，情绪已成立可少解释 |
| 鲜明立场／平视 | 判断可以鲜明，口气不必命令，真实条件仍保留 |
| 写逐字稿／别像念稿 | 写清楚有助推敲，说出来还需交流情境；“不能背稿”不是通用禁令 |
| “只有／一定”／保留条件 | 确为必要条件或确定事实才能这样说，不把可能、建议、相关性变必然因果 |
| 标题口语／正文准确 | 同一作者声音不等于正文照标题的句长、标点或粗俗程度 |

## 成稿质量回读

事实保留只是底线。修改完应把稿子当成第一次见到它的人来读，检查以下实际效果，而不是给自己打一个笼统高分：

- **自然**：是否只是把“具有重要意义”换成“很重要”？报告腔仍承担不了说明作用时，用现有内容把意思说清，别继续换同义词。
- **好懂**：人物、对象、比较、定义与主干是否能一次读清？在角色或所属词组中间插解释，可能让读者先读到错误的关系。先抽出“谁是什么／谁给谁做什么”的完整主干，再安放解释；不因名词都在就认定关系没变。
- **推进**：每段增加了什么？新例子或类比是否真的降低理解负担，还是又讲一遍？段尾已经由事实表达出的意思，无需再加抽象总结。
- **具体且有分寸**：已有动作、场景、数字或选择是否被空泛评价淹没？需要情绪时能从这些材料感到，还是只剩情绪标签？没有素材的地方不造细节。
- **像这类作品、像这个作者**：公众号段落仍能顺着读，口播句子能说完整，短文案让人明白用途；原有立场和好的表达有没有被改平或改成另一种腔调？

对最影响本篇效果的修改，能说明“原句→改句→具体收益”。明显问题仍在就继续改；仅有个人风格偏好、两种都自然时不反复折腾。已经好的控制段落可以完全保留。此回读是模型的文本检查，不能宣称本人已试读或用户已认可。

**检查所选方法是否真的起作用。** 读过或引用了方法名称不算完成。以当前段落选用的方法为准，例如：
- 用对比时，核对两边在比什么、各自的具体结果、这段想让人看清哪条差异。已有明确结果，收句就扣住这个差异；不要把它抹成“没有更好／有一定价值／值得综合考虑”等泛泛评价，也别只总结对照的一半。结果已由相邻句讲清时可以直接停，不再添总结；口径不同或材料不支持时不能硬做优劣排名。
- 用画面或行为证据时，读者能否从给定动作看见原来的意思，而不靠追加形容词？用留白时，已有细节是否足够承载感受，还是把理解需要的关系一起删了？
- 用类比时，对应的是哪一个关系，是否比原解释更易懂？贴了日常事物的名字但仍需再解释一遍，不算完成这一方法的作用。

## 对照原稿复检

这是内部检查，不要求用户填表；无关项跳过。

1. **任务**：只诊断还是改稿、范围是否遵守？是否越界另选题、改标题、重构全文？
2. **命题**：谁做什么、作者支持／反对什么、比较谁与谁，是否一致？
3. **证据状态**：计划、声称、推测、已发生、实测是否混写？
4. **约束**：时间、范围、样本、数量、单位、否定、条件、例外是否丢失？“不上传录音”不能扩大成“数据完全不上网”。
5. **数字**：可用材料中完整的数字做有助理解的简单换算或列账，逐项核算并保留单位、条件和可选项；区分原始数与计算结果。缺项不估填，不从不同口径的时长推出效率提升，不把算术结果扩成市场或因果结论。
6. **身份**：别人的经历仍属于别人；“我／我们”不制造使用史、采访史或资历。
7. **引语**：原话原样保留且归属正确？转述有无包装成直接引语？
8. **衔接**：代词、转折、比较、回指是否仍对应？不能省关键限定来“变顺”。
9. **密度节奏**：删的是无用重复还是有意复现？段落有推进还是仅换抽象词？新增类比／例子是否帮助理解，而非把同一信息完整说两遍？
10. **分寸**：比喻更清楚吗？幽默、对白、情绪、称呼适合当前人和媒介吗？
11. **作者与锁定**：锁定句逐字保留；不把克制作者改成训人，不把观点磨成泛泛中立。
12. **说明也守边界**：理由不扩大主张、不假引原句，不声称未做的真人朗读、试听、发布或效果验证。

保留有效表达属于成功结果。无声音或用户认可时，不用“完全像本人”“已验证口播感”作完成结论。
